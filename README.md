# dependency-owners

Determine ownership of dependencies in a project.

Use `dependency-owners` to map dependencies in a manifest to the people or teams responsible for them.

## Installation

### Prerequisites

- Node.js 22 or higher

### Install with your package manager

```bash
npm add -D dependency-owners
```

```bash
pnpm add -D dependency-owners
```

```bash
yarn add -D dependency-owners
```

See the [documentation](docs/index.md) for a quick start and usage guides.
